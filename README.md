# Fridge Roast: One Line, Biggest Laugh

![make.fun](https://make.fun/badge/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb.svg)

Entry for the make.fun bounty **Fridge Roast: One Line, Biggest Laugh** — one line, at most 200 characters, roasting a smart fridge. A house judge compares the lines two at a time and the funniest takes the $5 pool.

Bounty: https://make.fun/c/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb

Referral: `4fxhr3y1`

## The line

> My fridge's ice maker has been 'installing update 4.2' since March — my $3,000 smart fridge now dispenses warm disappointment, one cube a day.

142 characters. One line. No setup the punchline doesn't need: a firmware update that never finishes, an ice maker that dispenses the opposite of ice.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
